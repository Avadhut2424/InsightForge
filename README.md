# InsightForge AI - Phase 1

This is the infrastructure skeleton for the InsightForge AI project.

## Folder Structure
- `/app/api`: Web server and API routes (FastAPI).
- `/app/agents`: Placeholder for future agent logic.
- `/app/db`: Placeholder for future database layer.
- `/app/ingestion`: Placeholder for future ingestion pipeline.
- `/app/mcp_servers`: Placeholder for future MCP server implementations.
- `/app/core`: Shared configuration and settings loader.
